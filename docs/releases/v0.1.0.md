# GeoResearch v0.1.0

`v0.1.0` is the first public release of GeoResearch for DeepSeek Harness. It
provides an evidence-grounded research workflow for literature review,
repository and paper reproduction, geospatial experiments, independent
validation, claim approval, and traceable manuscript preparation.

## Install

Use the exact installer version on Windows 10 or Windows 11 x64:

```powershell
$dshHome = Join-Path $env:USERPROFILE '.dsh'
npx --yes @georesearch/dsh-installer@0.1.0 install --dsh-home $dshHome
npx --yes @georesearch/dsh-installer@0.1.0 verify --dsh-home $dshHome
```

The installer is self-contained and does not modify the DeepSeek Harness source
tree or run installation work from `postinstall`.

## Included Capabilities

- Persistent research briefs, projects, artifacts, evidence, runs, reviews,
  claims, and writing packets.
- Crossref literature search, evidence-grade PDF handling, citation validation,
  and bounded read-only Git repository audit.
- Scientific file inspection across common document, archive, image,
  geospatial, HDF5, NetCDF, Parquet, SQLite, and notebook formats.
- Frozen geospatial and remote-sensing experiment specifications with managed
  Python execution and reproducible result records.
- Independent validation before claim approval and manuscript drafting from
  validated writing packets.
- Coordinator delegation to bounded literature, experiment, review, and
  writing specialists while authoritative state remains Host-owned.
- Automatic DeepSeek visual analysis with explicit native-model and OCR
  fallback paths.

## Compatibility

- DeepSeek Harness `0.1.0-rc.5` at commit
  `47f943859bef60e4160492346772ded9b24f765a`, with the verified GeoResearch
  compatibility patch.
- Cordis `4.0.1`.
- Node.js `^22.19.0` or `>=24.0.0`.
- Python 3.10 or newer for geospatial workflows; `rasterio` and `pyproj` are
  required for raster inspection and CRS normalization.

See the [compatibility matrix](../compatibility-matrix.md) for the complete
boundary.

## Release Integrity

The release contains 26 public packages under the `@georesearch` npm scope. The
packages were built from the annotated `v0.1.0` tag, published from a
GitHub-hosted workflow with npm SLSA provenance, and promoted to `latest` only
after every package version and attestation was verified.

GitHub Release assets include the exact package tarballs,
`release-manifest.json`, and `SHA256SUMS`. The manifest binds the package order,
source commit and tree, Harness identity, live Phase 7 evidence, byte lengths,
SHA-256 digests, and npm SHA-512 integrity values.

The complete Windows release gate covers 44 release criteria, the
self-contained clean-home installer lifecycle, DSH Standard conformance,
Windows DPAPI and filesystem behavior, scientific golden cases, and a public
Rasterio repository/PDF/GeoTIFF end-to-end workflow.

## Operations

Use `verify` after installation, after a Harness repair, and before an upgrade.
The installer also exposes `upgrade`, `recover`, and `uninstall`. See
[Installation and Operations](../installation-and-operations.md) for exact
procedures and recovery rules.
