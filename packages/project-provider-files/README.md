# @georesearch/dsh-project-provider-files

Host-private Phase 2 persistence for Workspace bindings, versioned project
events and snapshots, idempotent operation records, content-addressed
artifacts, project mutation leases, safe `deliverables/` materialization,
Windows named mutexes, and recovery scans.

The package does not register model tools and does not import DeepSeek Harness
APIs. It is consumed by the GeoResearch Project and Run services.
