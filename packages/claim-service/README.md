# `@georesearch/dsh-claim-service`

Phase 6 Host-side support assessment and session-derived user authorization for ClaimRecords.
Interactive approval is skipped only for an explicit direct-user blanket grant
or the effective `danger-full-access` permission bundle; support, integrity,
validity, and review eligibility checks remain mandatory.
The service builds WritingPackets from the complete eligible Claim set and derives
the exact evidence, result, validation, run, spec, and Artifact closure.
