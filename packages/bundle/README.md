# @georesearch/dsh-bundle

Host-plane bundle applied after `@deepseek-ai/dsh-base` and
`@deepseek-ai/dsh-web-app`. It disables Session Telemetry and installs the
activation guard, strict Phase 4 policy, Project Service, File Service,
Evidence Service, Run Service, Reproduction Service, lifecycle wrapper, and globally filterable tool
rows. The managed GeoResearch preset
retains its persona, skills, and prompt contributions; scoped tools from other
presets may shadow global rows.

The Phase 1, Phase 2, Phase 2.5, Phase 3, and Phase 4 probe rows are disabled in
normal operation. The installer enables all five for one temporary real Harness
boot. The reports verify the preserved foundations, strict Phase 4 policy,
Project, File, Evidence, Run, and Reproduction services, role-scoped tools,
Provider replay capability, PDF parser lineage, bounded read-only Git
capability, strict schemas, Host-only Evidence/Report commits, and telemetry
absence before an installation generation is committed.
